const showProjectDetailsPage = async (req, res) => {

Topic 4 — Error Handling.
Question 10 — Could you paste the error-handling middleware or relevant code from your project that handles 404 or 500 errors?

USER:
// Global error handler
app.use((err, req, res, next) => {
  // Log error details for debugging
  console.error("Error occurred:", err.message);
  console.error("Stack trace:", err.stack);
  // Determine status and template
  const status = err.status || 500;
  const template = status === 404 ? "404" : "500";
  // Prepare data for the template
  const context = {
    title: status === 404 ? "Page Not Found" : "Server Error",
    error: err.message,
    stack: err.stack,
  };
  // Render the appropriate error template
  res.status(status).render(`errors/${template}`, context);
});

ASSISTANT:
Excellent! This is global Express error-handling middleware, identified by four parameters (err, req, res, next). It logs error details, uses err.status or 500, chooses a 404 or 500 template, prepares context, and renders an error response. Passing err.message and err.stack to EJS is helpful for development but can expose internal details in production. Missing URLs don't automatically reach error middleware without a separate 404 handler.
